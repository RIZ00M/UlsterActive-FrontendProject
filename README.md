Project Structure

    Website/: The core folder containing all files for the live site.

        home.html: The main landing page.
        
        CSS/: All site styling and layout rules.

        Images/: All the images and favicons used in the website

        Javascript/: All the javascript interactive elements and logic.

        Videos/: All the video media used

        Webpages/: All the webpages in the website.

How to Run

    Clone this repository.

    Navigate to the MainWebsite folder.

    Open home.html in any modern web browser.

Built With

    HTML5 - Page structure

    CSS3 - Custom styling

    JavaScript - Client-side interactivity

    Draw.io - Wireframing and design
